# ADR-016: 안전재고 경고 및 발주 트리거

- 상태: 승인됨
- 범위: Module 5 (재고/구매관리)

## 상황

FR-5-1은 품목별 재고 현황 조회를 요구한다. 안전재고 이하로 떨어졌을 때 시스템이 어디까지 자동으로 대응해야 하는지(단순 경고 표시부터 자동 발주까지) 정해야 한다.

## 결정

**안전재고 이하로 떨어지면 재고현황 화면에 경고만 표시한다.** 자동 발주(구매요청서 자동 생성)는 이번 범위에서 배제한다 — 경고를 본 구매담당자가 수동으로 구매요청서를 작성하는 것까지만 지원한다.

```java
public boolean isBelowSafetyStock() {
    return currentStock <= safetyStock;
}
```

화면에서는 `item.currentStock <= item.safetyStock`인 품목에 경고 표시를 하고, 그 옆에 "+ 구매요청서 작성" 링크로 바로 이어준다(자동 생성이 아니라 사람이 확인하고 수동으로 작성).

## 근거

- 자동 발주는 "얼마나 발주할지"(재주문점, 경제적 주문량(EOQ), 리드타임 등) 정책이 필요한 별도의 복잡한 도메인이다. `erp_requirements.md`의 FR-5-1은 "조회할 수 있어야 한다"까지만 요구하고 자동 발주를 요구하지 않는다.
- ADR-014(품목별 결재 조건 배제)와 같은 원칙이다: 요구사항에 명시되지 않은 자동화/조건 분기를 미리 만들지 않는다. Module 4의 `BudgetThresholdPolicy`처럼 "있으면 좋을 것 같아서" 만든 기능이 결국 아무도 쓰지 않는 죽은 코드가 되는 패턴을 반복하지 않는다.

## 트레이드오프

- 구매담당자가 재고현황 화면을 직접 확인하지 않으면 안전재고 이하 상태를 놓칠 수 있다(푸시 알림이나 이메일 통지가 없음). 실제 서비스라면 배치 알림이 필요하지만, 이번 범위에서는 화면 경고로 충분하다고 판단했다.
